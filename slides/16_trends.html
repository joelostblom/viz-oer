Trends

Learning outcomes

  1. Use means and rolling averages to summarize patterns while retaining the observations as context.
  2. Distinguish global regression models from local smoothing, and choose a trendline according to the question and audience.
  3. Adjust smoothing neighborhoods and explain how they affect the local detail shown by a curve.
  4. Recognize that describing a trend within the observed data does not justify extrapolating it beyond that range.

Why bother?

  • A trendline can make a general pattern easier to see when individual observations or multiple groups obscure it.

In Connections, lines connected observations to show relationships and changes. Here we use lines to summarize a pattern rather than connect every observation. A trendline can make a general pattern easier to see when individual observations or multiple groups obscure it. Trendlines are also called fitted lines or lines of best fit. The choice of line determines which features of the data are emphasized. Here we focus on the summaries themselves and keep the observations visible. In ?@sec-uncertainty, we add intervals and distinguish the spread of observations from uncertainty in an estimated mean.

We use automobile specifications from the Vega datasets collection, with missing horsepower observations omitted and the year represented numerically.

A simple summary is the mean horsepower for each year and origin. This works here because each year has several observations. For a more continuous x variable, binning or smoothing may be needed to avoid a noisy line driven by individual observations.

Altair

ggplot

A moving or rolling average uses a neighborhood of observations. Because there are several cars at each year, we first calculate the annual means and then smooth those means within each origin. This weights each annual mean equally, rather than weighting years by their number of cars.

A linear trend

  • Altair
  • ggplot
points + points.mark_line(size=3).transform_regression(
    'Year', 'Horsepower', groupby=['Origin']
)
car_points + geom_smooth(method = 'lm', se = FALSE, linewidth = 1.2)

Another way to show a trend is regression. Linear least-squares regression fits a straight line by minimizing the sum of squared vertical deviations from the observations to the line.

Altair

Regression is not restricted to straight lines. For example, a polynomial of order two gives a quadratic fit.

ggplot

Set the smoothing method to lm for a linear model. se = FALSE hides ggplot’s default confidence band, matching the line-only Altair example. That default band describes uncertainty in the fitted mean, not the standard deviation of individual observations.

The formula can be changed to fit a polynomial.

A polynomial trend

  • ggplot
points + points.mark_line(size=3).transform_regression(
    'Year', 'Horsepower', groupby=['Origin'], method='poly', order=2
)
car_points +
    geom_smooth(method = 'lm', formula = y ~ poly(x, 2), se = FALSE, linewidth = 1.2)

Local smoothing

  • Local regression fits nearby observations in overlapping neighborhoods, allowing the trend to change across the x-axis.

Sometimes one equation is a poor description of the whole dataset. Local regression fits nearby observations in overlapping neighborhoods, allowing the trend to change across the x-axis. This is usually called LOESS (locally estimated scatterplot smoothing) or LOWESS (locally weighted scatterplot smoothing). The animation builds up the red fitted curve from local fits.

How local regression builds a curve

A local trend

  • Altair
  • ggplot
points + points.mark_line(size=3).transform_loess(
    'Year', 'Horsepower', groupby=['Origin'], bandwidth=0.5
)
car_points + geom_smooth(
    method = 'loess', span = 0.5, se = FALSE, linewidth = 1.2,
    method.args = list(degree = 1, family = 'symmetric')
)

Altair

bandwidth controls the fraction of observations included in each neighborhood. Larger fractions usually give a smoother, more general curve. The default is 0.3; here we explicitly use 0.5 in both languages. A bandwidth of 1 uses all observations in each neighborhood, but is not generally identical to a single global linear regression.

ggplot

For these small groups, geom_smooth() uses LOESS by default. We set the method and neighborhood fraction explicitly here, and hide the confidence band as in the Altair example. We also request local linear fits and robust fitting to more closely match Vega’s LOESS implementation; R otherwise uses local quadratic fits by default. The implementations still need not produce identical curves, especially with repeated x-values such as the model years here.

The span parameter changes the fraction of observations in each neighborhood.

When to choose which trendline?

  • Means and rolling averages are useful when the summarized values should have a straightforward interpretation. They can be particularly accessible to a general audience.
  • Regression models are useful when a simple equation is a reasonable description of the relationship. Predictions beyond the observed range rely on that model continuing to hold, and become more uncertain as they move further from the data.
  • LOESS is useful for describing patterns within the observed data without choosing one global equation. It often resembles the trend a reader would sketch by eye, but depends on the smoothing setting and is poorly suited to extrapolation.
