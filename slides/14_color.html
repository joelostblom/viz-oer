Color

Learning outcomes

  1. Choose categorical, sequential, or diverging color schemes according to the meaning of the data.
  2. Use perceptually appropriate and accessible palettes, and set color domains and directions deliberately.
  3. Apply predefined and custom palettes in Altair and ggplot.
  4. Highlight and annotate selected observations using color and text without adding unnecessary clutter.
  5. Order legends to match the chart, or label series directly when that makes identification easier.

Why bother?

  • A color scheme should make those meanings easier to see, rather than introduce patterns that are not present in the data.

Color can distinguish groups, communicate numerical magnitude, or draw attention to a particular observation. A color scheme should make those meanings easier to see, rather than introduce patterns that are not present in the data. This chapter builds on the grouping channels in Groups and the communication choices in Communication.

Facilitate interpretation through informed color choices

  • A sequential palette with steadily changing lightness makes low-to-high values easier to interpret than a palette with unrelated bright and dark patches.

For continuous data, a perceptually uniform colormap is often a useful starting point. Equal steps in the data should produce approximately equal perceived changes in color. Lightness is especially important for conveying ordered magnitude: a sequential palette with steadily changing lightness makes low-to-high values easier to interpret than a palette with unrelated bright and dark patches. The Matplotlib colormap guide contains examples, and this talk about viridis explains many of the design principles.

Color vision and accessibility

  • Do not rely on a color distinction that some readers cannot see.

Color vision deficiencies affect a substantial number of readers. Red–green deficiencies are more common among men than women, and their prevalence varies across populations. Do not rely on a color distinction that some readers cannot see. The same guidelines often improve a chart for readers with typical color vision too.

The Coblis simulator can simulate different color vision deficiencies for an uploaded image. The cividis palette was designed to give similar perceptual ordering to readers with and without common red–green deficiencies. For categorical groups, redundant shapes or direct labels can help in addition to choosing colors carefully.

Avoid artificial boundaries

  • Choose a palette whose perceptual changes support the comparison you want readers to make.

The jet rainbow colormap has sharp changes in hue and uneven lightness. Yellow and cyan regions can attract disproportionate attention, creating apparent boundaries or features in otherwise smoothly varying data. Because higher values are not consistently lighter, the order is also hard to recover in grayscale.

Choose a palette whose perceptual changes support the comparison you want readers to make. For more examples, see How bad is your colormap? and The rainbow is dead … long live the rainbow. The turbo palette improves some shortcomings of jet, but does not make every rainbow palette perceptually uniform or suitable for every reader. Viridis or cividis are often better defaults for ordered values. For a broader discussion, see how color determines what we see.

Categorical color schemes

  • Categorical palettes distinguish groups without implying a low-to-high order.

Categorical palettes distinguish groups without implying a low-to-high order. We use iris measurements to compare the three species.

Distinguish categories

  • ggplot
iris_points = alt.Chart(iris).mark_circle(size=100).encode(

    y='petalLength',

Altair

Altair’s default categorical palette is tableau10, a sequence of ten colors beginning with blue, orange, and red.

Set the palette by name with scheme inside alt.Scale. The Vega scheme reference lists categorical, sequential, diverging, and cyclic palettes.

ggplot

The default categorical scale in ggplot selects equally spaced hues from a color wheel.

ColorBrewer palettes are available through scale_color_brewer() and scale_fill_brewer() for categories. The distiller scales interpolate these palettes for continuous values.

Choose a predefined palette

  • Altair
  • ggplot
iris_points.encode(color=alt.Color('species').scale(scheme='dark2'))
iris_points + scale_color_brewer(palette = 'Dark2')

Altair

You can also supply colors explicitly, using names or hexadecimal codes. Here the order of the color range corresponds to the order of the species domain.

ggplot

The Tableau palette used by Altair is available through ggthemes. The R color palettes collection shows many other choices and the packages that provide them.

Here we specify the same colors as the Altair example using their hexadecimal codes. Naming the values makes the mapping to species explicit.

Specify the mapping explicitly

colors = ['coral', 'steelblue', 'rebeccapurple']

ggplot

Experimenting with custom palettes can be useful, but well-designed existing palettes incorporate considerable research and testing. They are a good starting point for a final communication figure. Hexadecimal RGB codes range from #000000 for black to #ffffff for white. An image editor or online color picker can help recover the exact code for a color in an existing image.

Sequential color schemes

  • Sequential palettes communicate increasing or decreasing magnitude.

Sequential palettes communicate increasing or decreasing magnitude. When working on a light background, it is often useful for low values to be closest to that background and larger values to be more visually prominent. Consider the background, the palette direction, and the meaning of high values together.

Show numerical magnitude

  • ggplot

Mapping petal width to color selects a continuous palette.

The palette can be changed in the same way as for categories.

Viridis was developed for Matplotlib and is now available in many visualization tools. It uses changes in lightness and hue while aiming to preserve perceptual ordering.

Mapping a numerical variable to color uses a continuous scale.

Use scale_color_viridis_c() for a continuous viridis palette. The _d variant is for discrete values.

A perceptually designed palette

  • Altair
  • ggplot
iris_points.encode(color=alt.Color('petalWidth:Q').scale(scheme='viridis'))
iris_numeric + scale_color_viridis_c()

Reverse the palette with reverse=True, just as for the axis scales in Communication.

ggplot

A reverse transformation reverses the numerical color scale, which also reverses the ordering of the legend values.

To reverse only the palette while preserving the legend’s numerical order, use direction = -1 instead.

Reverse the palette deliberately

Diverging color schemes

  • Diverging palettes distinguish departures on either side of a meaningful midpoint.

Diverging palettes distinguish departures on either side of a meaningful midpoint. For example, a correlation ranges from −1 to 1 and has a natural midpoint at zero. A sequential palette can make a value near zero look more important than a strongly negative correlation simply because zero is numerically larger.

We calculate a correlation matrix from the Gapminder example data. The numeric cluster identifier is excluded because its codes are categories, not a quantitative measurement. The point here is to compare color encodings, not to infer causal relationships from these correlations.

A midpoint changes the color question

  • Altair
  • ggplot
correlation_heatmap = alt.Chart(corr_df, width=240, height=240).mark_rect().encode(
    x='variable_x:N',
    y='variable_y:N',
    tooltip='correlation:Q',
    color='correlation:Q'
)
correlation_heatmap
correlation_heatmap <- ggplot(corr_df, aes(x = variable_x, y = variable_y, fill = correlation)) +
    geom_tile()
correlation_heatmap

Altair

First, notice how the default sequential scale treats zero.

Choose a diverging palette and set the domain to the full possible correlation range. The symmetric limits make equal-magnitude positive and negative correlations comparable.

ggplot

The same correlation matrix can be computed directly in R.

ggthemes provides a Tableau diverging palette.

ColorBrewer offers alternatives through scale_fill_distiller(). The palette direction should agree with any relevant familiar association, such as red for warmer temperatures; the sign of a correlation has no inherent color.

Specify symmetric limits to make equal-magnitude departures from zero equally prominent.

Center the palette on a meaningful value

  • Altair
  • ggplot
correlation_heatmap.encode(
    color=alt.Color('correlation:Q').scale(domain=[-1, 1], scheme='purpleorange')
)
correlation_heatmap + scale_fill_distiller(palette = 'PuOr', limits = c(-1, 1))

Altair

Alternatively, domainMid=0 identifies the midpoint and selects a default diverging palette.

Highlighting with colors

  • Give the observation of interest a distinct color while leaving the other observations as context.

Color can also select a small part of a chart for attention. We use historical wheat prices after 1700, with fewer bars to keep the example readable. Give the observation of interest a distinct color while leaving the other observations as context.

Highlight one observation

  • Altair
  • ggplot
wheat['highlight'] = wheat['year'] == 1810
bars = alt.Chart(wheat).mark_bar().encode(
    x='year:O',
    y='wheat:Q',
    color='highlight:N'
)
bars
wheat <- wheat |> mutate(highlight = year == 1810)
bars <- ggplot(wheat, aes(x = year, y = wheat, fill = highlight)) +
    geom_col(color = 'white') + ggthemes::scale_fill_tableau()
bars

Add exact values

  • Altair
  • ggplot
bars + bars.mark_text(dy=-5).encode(text='wheat:Q')
bars + geom_text(aes(label = wheat), vjust = -0.3)

An exact value can make an important comparison easier to read. Text can also explain why an observation is highlighted. Keep in mind that labeling every observation may add more clutter than information.

Altair

Layer a text mark above the bars.

The text inherited the bar chart’s color encoding. An encoding takes precedence over a color set directly in the mark. To override it, set a literal encoding value with alt.value(); otherwise a string in an encoding is interpreted as a data column name.

ggplot

Use geom_text() with the label aesthetic.

To match the text to the highlighted bar colors, map the color aesthetic and add a corresponding color scale. This is separate from the fill scale used by the bars.

Control annotation colors

  • Altair
  • ggplot
bars + bars.mark_text(dy=-5).encode(text='wheat:Q', color=alt.value('black'))
bars +
    geom_text(aes(label = wheat, color = highlight), vjust = -0.3) +
    ggthemes::scale_color_tableau()

Altair

ggplot

When a label represents a computed count rather than a precomputed value, use a layer with the same counting statistic, for example geom_text(stat = 'count', aes(label = after_stat(count))).

Let the annotations do useful work

  • Altair
  • ggplot
bars = bars.encode(y=alt.Y('wheat:Q').axis(grid=False))
bars + bars.mark_text(dy=-5).encode(text='wheat:Q', color=alt.value('black'))
bars +
    geom_text(aes(label = wheat, color = highlight), vjust = -0.3) +
    ggthemes::scale_color_tableau() +
    theme(panel.grid.major = element_blank(), panel.grid.minor = element_blank())

Annotate selected observations

  • Often only the highlighted observation needs a label.

Often only the highlighted observation needs a label. Filtering the annotation data leaves the other bars intact.

Label only what needs explanation

  • Altair
  • ggplot
bars + alt.Chart(wheat.query('year == 1810')).mark_text(dy=-5).encode(
    x='year:O', y='wheat:Q', text='wheat:Q'

Altair

For custom annotation text, use a literal value again.

ggplot

Supply filtered data to the text layer, rather than filtering the whole chart.

For a fixed annotation, annotate() avoids adding a data column.

Explain why the observation matters

  • Altair
  • ggplot
bars + alt.Chart(wheat.query('year == 1810')).mark_text(dy=-5, dx=-30).encode(
    x='year:O', y='wheat:Q', text=alt.value('The record year')
)
bars + annotate('text', label = 'The record year', x = 1810, y = 102, hjust = 1)

Altair

Direct labeling instead of using a legend

  • Matching the legend’s order to the visible order of the series reduces that effort; direct labels can remove the lookup entirely.

A legend can make the reader repeatedly look away from the plotted marks. Matching the legend’s order to the visible order of the series reduces that effort; direct labels can remove the lookup entirely. The stock-price data provide an example where alphabetical order does not match the order of the line endpoints.

The legend and chart can have different orders

  • Altair
  • ggplot
stock_lines = alt.Chart(stocks).mark_line().encode(
    x='date:T', y='price:Q', color='symbol:N'

stock_lines
stock_lines <- ggplot(stocks, aes(x = date, y = price, color = symbol)) +
    geom_line() + ggthemes::scale_color_tableau()
