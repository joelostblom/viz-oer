Plotting each individual observation separately is one of the most direct ways to visualize data. Rather than summarizing groups of observations, we’re simply putting one graphical point in our chart for every record in our table. As we saw in the introductory chapter, even this simple form of visualization can reveal patterns that are difficult to spot in a table of numbers.

It’s time to start coding! First, we need some example data to visualize. Libraries that implement a grammar of graphics generally work with “tidy” data. In tidy data, each column represents a variable (also called a field), and each row represents an observation. We will start by loading a small historical dataset with information about cars’ design, performance, and fuel efficiency.

Looking at the table above, we might start to generate questions about our data. Perhaps the cars with the best fuel efficiency are also the cars with the least powerful engines (i.e. do the cars with the highest Miles_per_Gallon also have the lowest Horsepower)? This sounds reasonable since a more powerful engine generally uses more fuel. Let’s see if we can answer this question with a visualization. To see how these two variables relate to each other, we can map them to two visual channels in the chart, such as x and y.

Horsepower vs Miles_per_Gallon

  • Altair
  • ggplot
alt.Chart(cars).mark_point().encode(
    x='Miles_per_Gallon',
    y='Horsepower'
)
ggplot(cars, aes(x = Miles_per_Gallon, y = Horsepower)) +
    geom_point()

  • What can you say about the relationship between Horsepower and Miles_per_Gallon?

From the chart, we can see that Horsepower and Miles_per_Gallon are “negatively correlated”. In plain English, this means that cars with more powerful engines (higher Horsepower) tend to have lower fuel efficiency (lower Miles_per_Gallon). This makes sense, as more powerful engines often consume more fuel than less powerful ones. Note that we can’t make claims about a causal relationship from the chart alone, but in this case, the observed relationship in the chart supports our mechanistic understanding of the world.

Our conclusion above makes sense for the data we showed in the chart. But remember that there are other variables in our dataframe; let’s show it again as a reminder.

What if one of the other variables also influences a car’s fuel efficiency? For example, it seems reasonable that the weight of the car could impact fuel efficiency, since more energy is needed to accelerate a heavier car to the same speed. To explore Weight_in_lbs together with the other two variables, we can use another visual channel in this chart, for example, by coloring the points according to this column. When using the color encoding channel, high-level visualization libraries will automatically figure out an appropriate color scale to use. Since the Weight_in_lbs column contains continuous numerical data, a continuous gradient will be used here.

Adding a quantitative color encoding

  • Altair
  • ggplot
alt.Chart(cars).mark_point().encode(
    x='Miles_per_Gallon',
    y='Horsepower',
    color='Weight_in_lbs'
)
ggplot(cars, aes(x = Miles_per_Gallon, y = Horsepower, color = Weight_in_lbs)) +
    geom_point()

  • How does a car’s weight relate to its fuel efficiency?

  • Is the color or position easier to read?

Altair

Here, we add the color encoding to the chart so that we can see how all three variables relate to each other. Note that the largest value in the Weight_in_lbs column is represented with a dark color, which contrasts strongly with the light background of the chart.

ggplot

Here, we add the color encoding to the chart so that we can see how all three variables relate to each other. The default color gradient runs from dark blue for lower weights to light blue for higher weights, since light colors have the highest contrast to the chart’s dark background.

Exercise

How does a car’s weight relate to its fuel efficiency?

Hint

Use the color legend to find the heaviest cars. Where do they fall on the fuel-efficiency axis? Compare them with the lightest cars, then check how their horsepower differs too.

Solution

We can see that Weight_in_lbs is positively correlated with Horsepower and negatively with Miles_per_Gallon. This aligns with our knowledge about the world: heavier cars generally need more energy to accelerate to the same speed, and the heavier cars in this dataset tend to have more powerful engines. However, remember that we can’t establish causation from the chart alone. We can only note that the correlation matches what we would expect based on our knowledge about the physics of moving objects.

Is the color or position easier to read?. You might already have noticed that it was harder to read exact values from the color scale than from the x- and y-axes. This is an important consideration, and we will dive deeper into which visual channels are the most effective at presenting information in the next chapter.
